About OpenVPN UI

Version {{ .AppVersion }}
A web interface for administering an OpenVPN server: certificates, 2FA, server settings, logs and email alerts. This is a personal hobby project, provided free of charge and without any warranty.

Source code and changelog: github.com/dubey-omprakash/openvpn-ui
OpenVPN server image: github.com/dubey-omprakash/openvpn-server

Credits

  • Based on d3vilh/openvpn-ui by Mr.Philipp (d3vilh), which in turn builds on work by Adam Wałach.
  • d3vilh/openvpn-server-config is used as a library.
  • Built with Beego, AdminLTE, Bootstrap, jQuery, Ace and other open source components. Their licences are listed in THIRD-PARTY-NOTICES.md.
  • Runs together with OpenVPN and EasyRSA.
